Rent the computers. Skip the data center.

Amazon Web Services lets you use servers, storage and databases over the internet and pay only for what you use.

Your app

A website, a mobile backend, a nightly report. This is the part you write.

EC2 for servers

Virtual machines you start in a minute and stop when you are done.

S3 for files

Storage for images, backups and static websites, with very high durability.

RDS for databases

Managed MySQL, PostgreSQL and others, with backups handled for you.

Lambda for small functions

Run code only when something happens. No server to look after.

New to AWS? Start with S3. Upload a file, turn on static hosting, and you have a live website.

Learn more at aws.amazon.com/getting-started.
